Provenance & taint tracking

User and system content is trusted; tool output is not. AgentGuard knows which arguments came from a web page, an email or a file - including encoded and paraphrased copies.

Injection detection

Multilingual heuristic rules, an on-device ONNX classifier and an optional LLM judge score every tool result for hidden instructions.
